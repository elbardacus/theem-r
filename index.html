🔌 Bridg-r — Scanner Setup
The memory scanner talks to your emulator over HTTP, but EmuLnk emulators communicate over UDP — a protocol browsers can't speak directly. Bridg-r sits in the middle: it accepts HTTP from Theem-r and translates it to EMLKV2/UDP for the emulator.

↗ Bridg-r on GitHub
📱  Running Theem-r directly on your Android device?
Run Bridg-r in Termux on the same device. Set DEVICE_IP = "127.0.0.1" in bridgr.py, run it, then open Theem-r in Chrome on the same device. No Wi-Fi or desktop needed — everything stays local.
Requirements
Python 3.10+ — free, no extra packages needed.
↗ Download Python
Setup (one-time)
1 Find your device's Wi-Fi IP — Android Settings → About phone → Status → IP address (e.g. 192.168.1.50). Your PC and device must be on the same Wi-Fi network.
2 Download bridgr.py, open it in a text editor, and set DEVICE_IP to your device's IP:
DEVICE_IP = "192.168.1.50" Copy
↗ Download bridgr.py
3 Run Bridg-r on your desktop — keep this window open while scanning:
python bridgr.py Copy
Connect in Theem-r
4 Set IP to 127.0.0.1, port 55355, then click Test — green dot means live.
💡  Emulator developer? The Bridg-r Emulator SDK lets you embed the HTTP API directly in your fork — no script needed for users. Drop-in C++ with copy-paste examples for Dolphin-Lnk, PPSSPP-Lnk, melonDS-Lnk, and more.
